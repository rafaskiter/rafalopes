# Imagens do case Olho Mágico

Salve as 5 imagens do projeto **exatamente** com estes nomes nesta pasta
(`public/cases/olho-magico/`). Enquanto os arquivos não existirem, o site mostra
placeholders automaticamente — assim que salvar, as telas reais aparecem.

| Arquivo         | Imagem (qual usar)                                                            | Onde aparece              |
|-----------------|------------------------------------------------------------------------------|---------------------------|
| `cover.png`     | Slide "Sistema administrativo para Imobiliárias e app Inquilino" (dashboard) | Card do projeto + capa    |
| `artefatos.png` | Slide "Artefatos" (boards do workshop / priorização de dores)                | Bloco "Processo"          |
| `entregue.png`  | Slide "O que foi entregue?" (foto da família + itens)                        | Bloco "Entrega"           |
| `sistema.png`   | Montagem das telas do sistema (login, usuários, contratos, detalhe)          | Bloco "Sistema"           |
| `app.png`       | Telas do app do inquilino (login, home, histórico de pagamentos)             | Bloco "App do inquilino"  |

Formato recomendado: PNG (ou JPG/WebP, mas mantenha o **nome** com a extensão
`.png` ou ajuste o `src` em `content/projects.ts`). Pode otimizar antes de salvar
(o ideal é largura ~1600–2000px).
